# topnotch-website

The one-page site for [TopNotch](https://github.com/Yasharma117/TopNotch), a teleprompter that lives in your Mac's notch.

```bash
npm install
npm run dev
```

`src/lib/notch.ts` and `src/lib/script.ts` are ports of the app's notch geometry and spring; keep them faithful to the Swift source. Tests: `npx vitest run`.
